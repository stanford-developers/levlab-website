# LevLab website

Public website for the research group of Professor Benjamin Lev at Stanford University.

Preview: https://stanford-developers.github.io/levlab-website/

GitHub Pages publishes the finished website files on this `main` branch from `/ (root)` using **Deploy from a branch**, following Stanford knowledge article KB00020629. The homepage is `index.html`. There is no custom GitHub Actions workflow.

Editable source and maintenance instructions are on the [`source` branch](https://github.com/stanford-developers/levlab-website/tree/source). Routine updates are built and checked locally, then committed to `main` for automatic publication.

Site owner: Professor Benjamin Lev — benlev@stanford.edu.

Technical web administrator: Pranav Parakh — pdparakh@stanford.edu.

The move to levlab.stanford.edu is coordinated separately with Stanford Web Services and Stanford IT.
